01
Sensing
Simulated collar readings: core temperature, heart rate, 3-axis activity, rumination — sampled every simulated 30 minutes, mirroring the 1–5 min collar interval at demo speed.
02
Connectivity
Represented here as the in-browser tick loop standing in for the LoRaWAN/cellular + MQTT transport layer.
03
Edge computing
Each tick computes personalized baseline deviation, rate-of-change, HR zone, and a lameness probability score client-side — no server round trip, matching the edge-inference design.
04
ML ensemble
Three lightweight stand-ins for the poster's models: a classifier (Model A), a multivariate outlier detector (Model B), and a trend/slope model (Model C). An alert fires only on ≥2-model consensus.
05
Alert engine
Critical / Warning / Trending tiers, triggered by the same thresholds described in the design: sustained temperature deviation, HR zone breach, immobility, rumination cessation, or composite wellness score.
06
Data & insights
In-memory rolling history per animal (last 24 simulated hours) drives the trend charts — standing in for the time-series store.
07
Farmer / vet interface
This dashboard: color-coded herd view + quick actions for farmers, diagnostic reasoning + model votes for vets.

Prototype scope: 12 simulated animals, rule-based stand-ins for the SVM / Isolation Forest / LSTM ensemble, and no real hardware, network, or cloud layer — built to demonstrate the decision logic and UX of the full architecture end to end.
